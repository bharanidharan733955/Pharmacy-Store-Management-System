# 💊 Pharmacy Store Management System

A production-oriented **Java Full Stack Pharmacy Store Management System** designed to manage medicines, suppliers, batch-wise inventory, purchases, expiry tracking, POS billing, scheduled drugs, invoices, returns, and sales reports.

The system is built using **Java, Spring Boot, Spring Security, MySQL, React.js, and REST APIs**, with a focus on security, transaction integrity, maintainability, performance, and real-world pharmacy workflows.

---

## 📌 Project Overview

The Pharmacy Store Management System provides a centralized platform for managing day-to-day pharmacy operations.

The application supports three primary roles:

- **Admin**
- **Pharmacist**
- **Cashier**

The system manages the complete flow:

```text
Medicine Management
        ↓
Supplier Management
        ↓
Purchase Entry
        ↓
Batch Creation
        ↓
Inventory Management
        ↓
POS Billing
        ↓
FEFO Batch Selection
        ↓
Invoice Generation
        ↓
Sales & Stock Reports
        ↓
Expiry Management & Returns
